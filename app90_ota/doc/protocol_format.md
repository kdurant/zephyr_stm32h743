# 通信协议格式


| 字节偏移 | 名称         | 长度（B） | 内容                             | 备注        |
| -------- | ------------ | --------- | -------------------------------- | ----------- |
| 0        | 帧头         | 2         | 0x12 0x34                        |             |
| 2        | 帧序号       | 2         | 0x0000-0xFFFF                    | 每帧次+1    |
| 4        | 源地址       | 2         | 0x00：上位机软件<br>0x10：采集卡 | 信息来源    |
| 6        | 目的地址     | 2         |                                  | 信息去向    |
| 8        | 总包数       | 2         |                                  | 默认为1     |
| 10       | 包序号       | 2         |                                  |             |
| 12       | 指令         | 2         |                                  |             |
| 14       | 数据有效长度 | 2         |                                  |             |
| 16       | 数据区       | 65535     | 设备参数：默认长度4字节          | 不大于65536 |
| 65551    | 保留         | 1         |                                  |             |
| 65552    | 保留         | 1         |                                  |             |
| 65553    | 帧尾         | 1         | 0xcd                             |             |
| 65554    | 帧尾         | 1         | 0xef                             |             |
- 指令需要响应时：使用原指令号进行响应
- 协议执行的命令失败时，返回4个字节的0xff
