# PC 与 MCU 通信指令集 — OTA 固件升级

## 1. 概述

本文档基于通信协议格式，定义上位机（PC）与设备端（MCU）之间进行 OTA 固件升级所需的指令集。

### 协议基础

| 项目     | 取值                    |
| -------- | ----------------------- |
| 帧头     | 0x12 0x34               |
| 帧尾     | 0xCD 0xEF               |
| 源地址   | 0x00：上位机（PC）      |
| 目的地址 | 0x20：设备端（OTA 设备） |
| 指令响应 | 使用原指令号进行响应    |
| 失败响应 | 数据区返回 4 字节 0xFF  |

> 所有多字节数据均采用 **小端序（Little-Endian）** 传输。

---

## 2. 地址定义

| 地址值 | 含义             |
| ------ | ---------------- |
| 0x00   | 上位机（PC）     |
| 0x10   | 采集卡           |
| 0x20   | 设备端（OTA 设备） |

---

## 3. 指令集总览

| 指令码 | 名称             | 方向      | 说明                     |
| ------ | ---------------- | --------- | ------------------------ |
| 0x0001 | 握手             | PC → MCU  | 检测设备在线与协议版本   |
| 0x0002 | 获取设备信息     | PC → MCU  | 获取 MCU 型号、固件版本等 |
| 0x0003 | 开始升级         | PC → MCU  | 启动 OTA 升级流程        |
| 0x0004 | 传输固件数据     | PC → MCU  | 传输固件分包数据         |
| 0x0005 | 传输完成         | PC → MCU  | 通知固件数据发送完毕     |
| 0x0006 | 校验固件         | PC → MCU  | 请求设备校验固件完整性   |
| 0x0007 | 复位运行         | PC → MCU  | 复位 MCU，运行新固件     |
| 0x0008 | 取消升级         | PC → MCU  | 取消本次升级流程         |
| 0x0009 | 查询升级状态     | PC → MCU  | 查询当前升级进度与状态   |
| 0x000A | 设置启动标志     | PC → MCU  | 设置/清除固件启动标志    |

---

## 4. 指令详细定义

### 4.1 0x0001 — 握手

**方向：** PC → MCU

**数据区（PC → MCU）：** 无

**数据区（MCU → PC）：**

| 偏移 | 名称       | 长度（B） | 内容                                     |
| ---- | ---------- | --------- | ---------------------------------------- |
| 0    | 设备状态   | 1         | 0x00：空闲<br>0x01：正在升级<br>0x02：已就绪 |
| 1    | 协议版本   | 2         | 主版本号(1B) + 次版本号(1B)，如 0x01 0x00 |

---

### 4.2 0x0002 — 获取设备信息

**方向：** PC → MCU

**数据区（PC → MCU）：** 无

**数据区（MCU → PC）：**

| 偏移 | 名称           | 长度（B） | 内容                       |
| ---- | -------------- | --------- | -------------------------- |
| 0    | MCU 型号       | 16        | ASCII 字符串，不足填 0x00  |
| 16   | 当前固件版本   | 4         | V+主版本+次版本+修订版本   |
| 20   | Flash 总大小   | 4         | 单位：字节                 |
| 24   | Flash 页大小   | 2         | 单位：字节                 |
| 26   | 已用 Flash 大小 | 4        | 单位：字节                 |
| 30   | 固件起始地址   | 4         | 默认固件存储起始地址       |

---

### 4.3 0x0003 — 开始升级

**方向：** PC → MCU

**数据区（PC → MCU）：**

| 偏移 | 名称         | 长度（B） | 内容                 |
| ---- | ------------ | --------- | -------------------- |
| 0    | 固件总大小   | 4         | 固件总字节数         |
| 4    | 固件 CRC32   | 4         | 整个固件的 CRC32 值  |
| 8    | 固件版本号   | 4         | V+主版本+次版本+修订版本 |

**数据区（MCU → PC）：**

| 偏移 | 名称         | 长度（B） | 内容                                       |
| ---- | ------------ | --------- | ------------------------------------------ |
| 0    | 状态         | 1         | 0x00：就绪，可接收数据<br>0xFF：拒绝升级    |
| 1    | 最大分包长度 | 2         | 单次传输固件数据的最大字节数（建议 1024）  |
| 3    | 擦除进度     | 1         | 0~100，Flash 擦除百分比                     |

> MCU 收到此指令后，应先擦除固件存储区域，完成后回复就绪状态。

---

### 4.4 0x0004 — 传输固件数据

**方向：** PC → MCU

**数据区（PC → MCU）：**

| 偏移 | 名称       | 长度（B） | 内容                          |
| ---- | ---------- | --------- | ----------------------------- |
| 0    | 数据偏移   | 4         | 本包数据在固件中的起始偏移地址 |
| 4    | 固件数据   | N         | 固件数据（N ≤ 最大分包长度）  |

**数据区（MCU → PC）：**

| 偏移 | 名称       | 长度（B） | 内容                                     |
| ---- | ---------- | --------- | ---------------------------------------- |
| 0    | 状态       | 1         | 0x00：成功<br>0x01：偏移错误<br>0xFF：失败 |
| 1    | 已接收偏移 | 4         | 当前已成功写入的固件总字节数              |

> PC 按分包长度将固件拆分为多帧发送，每帧使用递增的包序号（帧序号字段）。  
> MCU 每收到一包后应写入 Flash 并回复确认，PC 收到确认后再发下一包。

---

### 4.5 0x0005 — 传输完成

**方向：** PC → MCU

**数据区（PC → MCU）：**

| 偏移 | 名称         | 长度（B） | 内容                |
| ---- | ------------ | --------- | ------------------- |
| 0    | 固件 CRC32   | 4         | 整个固件的 CRC32 值 |
| 4    | 固件总大小   | 4         | 固件总字节数        |

**数据区（MCU → PC）：**

| 偏移 | 名称   | 长度（B） | 内容                           |
| ---- | ------ | --------- | ------------------------------ |
| 0    | 状态   | 1         | 0x00：确认完成<br>0xFF：失败   |
| 1    | 已接收大小 | 4      | MCU 实际收到的固件总字节数     |

> MCU 应在此阶段验证固件大小是否与声明一致。

---

### 4.6 0x0006 — 校验固件

**方向：** PC → MCU

**数据区（PC → MCU）：** 无

**数据区（MCU → PC）：**

| 偏移 | 名称         | 长度（B） | 内容                                   |
| ---- | ------------ | --------- | -------------------------------------- |
| 0    | 校验结果     | 1         | 0x00：CRC 匹配<br>0x01：CRC 不匹配<br>0xFF：校验失败 |
| 1    | 计算 CRC32   | 4         | MCU 实际计算的固件 CRC32 值             |

> MCU 对接收到的完整固件计算 CRC32，与 PC 下发的 CRC32 进行比对。

---

### 4.7 0x0007 — 复位运行

**方向：** PC → MCU

**数据区（PC → MCU）：**

| 偏移 | 名称       | 长度（B） | 内容                         |
| ---- | ---------- | --------- | ---------------------------- |
| 0    | 复位延迟   | 2         | 延迟时间，单位：ms，0 表示立即 |

**数据区（MCU → PC）：**

| 偏移 | 名称   | 长度（B） | 内容                         |
| ---- | ------ | --------- | ---------------------------- |
| 0    | 状态   | 1         | 0x00：即将复位<br>0xFF：拒绝复位 |

> MCU 回复确认后，延迟指定时间后执行系统复位，跳转到新固件运行。

---

### 4.8 0x0008 — 取消升级

**方向：** PC → MCU

**数据区（PC → MCU）：** 无

**数据区（MCU → PC）：**

| 偏移 | 名称   | 长度（B） | 内容                                   |
| ---- | ------ | --------- | -------------------------------------- |
| 0    | 状态   | 1         | 0x00：已取消，恢复旧固件<br>0xFF：取消失败 |

> MCU 收到后应清除已接收的固件数据，恢复旧固件运行标记。

---

### 4.9 0x0009 — 查询升级状态

**方向：** PC → MCU

**数据区（PC → MCU）：** 无

**数据区（MCU → PC）：**

| 偏移 | 名称         | 长度（B） | 内容                                        |
| ---- | ------------ | --------- | ------------------------------------------- |
| 0    | 升级阶段     | 1         | 0x00：空闲<br>0x01：擦除中<br>0x02：接收数据中<br>0x03：校验中<br>0x04：已完成<br>0xFF：异常 |
| 1    | 已接收字节数 | 4         | 当前已收到的固件字节数                      |
| 5    | 固件总大小   | 4         | 本次升级固件总大小                          |
| 9    | 错误码       | 1         | 0x00：无错误，其余值表示具体错误类型         |

---

### 4.10 0x000A — 设置启动标志

**方向：** PC → MCU

**数据区（PC → MCU）：**

| 偏移 | 名称       | 长度（B） | 内容                                       |
| ---- | ---------- | --------- | ------------------------------------------ |
| 0    | 启动标志   | 1         | 0x00：回滚到旧固件<br>0x01：标记新固件可用  |

**数据区（MCU → PC）：**

| 偏移 | 名称   | 长度（B） | 内容                           |
| ---- | ------ | --------- | ------------------------------ |
| 0    | 状态   | 1         | 0x00：设置成功<br>0xFF：设置失败 |

---

## 5. 升级流程示例

```
PC                              MCU
│                                │
├── 0x0001 握手 ────────────────→│
│←── 0x0001 握手响应 ────────────┤
│                                │
├── 0x0002 获取设备信息 ────────→│
│←── 0x0002 设备信息 ────────────┤
│                                │
├── 0x0003 开始升级 ────────────→│  (含固件大小 + CRC32)
│                                │  [MCU 擦除 Flash]
│←── 0x0003 就绪确认 ────────────┤  (含最大分包长度)
│                                │
├── 0x0004 固件数据包 #1 ───────→│
│←── 0x0004 确认 #1 ────────────┤
├── 0x0004 固件数据包 #2 ───────→│
│←── 0x0004 确认 #2 ────────────┤
│            ...                 │
├── 0x0004 固件数据包 #N ───────→│
│←── 0x0004 确认 #N ────────────┤
│                                │
├── 0x0005 传输完成 ────────────→│
│←── 0x0005 完成确认 ────────────┤
│                                │
├── 0x0006 校验固件 ────────────→│
│                                │  [MCU 计算 CRC32]
│←── 0x0006 校验结果 ────────────┤
│                                │
├── 0x000A 设置启动标志(可用) ──→│  (可选，标记新固件)
│←── 0x000A 设置成功 ────────────┤
│                                │
├── 0x0007 复位运行 ────────────→│
│←── 0x0007 确认复位 ────────────┤
│                                │  [MCU 延迟后复位]
│                                │  [跳转新固件运行]
```

## 6. 错误码定义

| 错误码 | 含义             | 说明                     |
| ------ | ---------------- | ------------------------ |
| 0x00   | 无错误           | —                        |
| 0x01   | 固件大小超限     | 固件超出 Flash 容量      |
| 0x02   | Flash 擦除失败   | 擦除操作异常             |
| 0x03   | Flash 写入失败   | 写入操作异常             |
| 0x04   | CRC 校验不匹配   | 固件完整性校验失败       |
| 0x05   | 偏移地址错误     | 数据包偏移不连续或越界   |
| 0x06   | 超时错误         | 等待数据超时             |
| 0x07   | 版本回退         | 新固件版本低于当前版本   |
| 0xFF   | 未知错误         | 其他未定义错误           |
